# Logo

**Sygnet** (`steadystate-mark.svg`): krzywa odpowiedzi układu — skok, wygasające oscylacje i płaska linia zakończona kropką (stan ustalony). Atramentowy błękit na grafitowym kwadracie `radius-lg`. Favicon, avatar, małe pola.

**Znak słowny na ciemnym tle** (`steadystate-wordmark-dark.svg`): wersja domyślna — krzywa `signal` + „steadystate” w `ink` na `surface`.

**Znak słowny na jasnym tle** (`steadystate-wordmark.svg`): do dokumentów, faktur, jasnych materiałów.

Zawsze jedno słowo, małe litery, Inter Tight 600. Pole ochronne: wysokość kropki × 2 z każdej strony. Nie obracaj krzywej, nie dodawaj gradientów ani cieni.
